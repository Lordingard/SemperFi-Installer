# Contributing

Report reproducible problems through GitHub issues. Include your Windows
version, tool version, source type, destination, exact message and relevant
log excerpts. Do not upload the game, its ISO or personal saves.

Keep changes focused and preserve the validated campaign, bitmap and media
fixes. Build with scripts/build.ps1 and run scripts/check-public-content.py.
Installation changes should also run scripts/test-installation.ps1 with
privately held source media. Gameplay claims require actual gameplay testing.

Contributions to original project code are submitted under the MIT license.
Preserve third-party notices and do not add proprietary game assets.
